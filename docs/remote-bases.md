# Fonder une base éloignée

Un paysan dispose de l’action **Fonder une base**. Elle ouvre une fiche avec le coût de l’avant-poste, les ressources manquantes et les conditions. La fondation coûte 1 PA et le coût de construction habituel de l’avant-poste, réduction de faction comprise ; ce coût reste supérieur à celui du campement.

Sur une terre neutre libre compatible (plaine, colline, forêt ou ruines), un paysan présent sur la case peut construire un avant-poste sans limite de distance aux bâtiments existants. Il faut débarquer les paysans transportés avant de fonder sur une île. Les terres ennemies, sites stratégiques, lieux d’expédition, bâtiments et unités adverses restent bloquants. L’ingénieur ou un paysan voisin ne suffisent pas pour cette exception.

Le catalogue Construire permet aussi cette fondation et contrôle l’accès séparément pour chaque bâtiment. Les autres constructions gardent les règles existantes : chantier neutre à trois cases maximum d’un bâtiment et bâtisseur à une case maximum, ou terrain déjà possédé. Les enceintes requièrent toujours leur bâtisseur.

L’avant-poste revendique seulement sa case ; le rayon de trois cases est une possibilité de construction, pas une capture automatique. Il forme des paysans et évolue ensuite en village. Le fondateur est conservé, la capitale ne change pas et la base reste attaquable selon les règles ordinaires. Aucun changement de sauvegarde ni migration de base de données.
