# Nombres de dégâts

Chaque attaque validée et chaque riposte de PNJ ou de garnison ajoute un rapport de dégâts structuré au journal serveur. La carte affiche le montant calculé pour le coup (le même que dans le compte rendu, y compris s’il dépasse les PV restants), au-dessus de la cible effectivement touchée : unité, bâtiment ou rempart intercepteur.

Les pertes du joueur sont rouges ; les coups sur les adversaires sont dorés. Les contre-attaques portent la mention « Riposte ». Les valeurs utilisent le format français avec au maximum une décimale. Les coups fatals restent visibles après disparition de la cible. Les coups successifs sont séparés et chaque identifiant de rapport n’est affiché qu’une fois.

Les prédictions ne produisent aucun nombre : celui-ci apparaît à la confirmation du serveur. Les anciens rapports, cases non visibles avant le combat et couches masquées ne déclenchent pas cet affichage. En mode animations réduites, les nombres restent fixes puis disparaissent. La vue stratégique masque ces détails.
