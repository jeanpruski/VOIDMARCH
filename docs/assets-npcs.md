# Figurines des rencontres neutres

Mode : outil intégré `image_gen`, une génération par figurine, avec `rad-infantry.png` comme référence de style. Cinq PNG RGBA transparents copiés dans le projet, alpha vérifié, inspection visuelle effectuée. Aucun détourage ni fond artificiel.

Les images sont normalisées par le moteur d’atlas existant pour la carte et les miniatures des panneaux.

## Prompt commun

```text
Use case: stylized-concept. Asset: one production game miniature PNG for VOIDMARCH.
Reference image STYLE ONLY; generate exactly ONE separate subject, not a sheet.
[SUBJECT]
Match the realistic painted tabletop figurine finish of the reference: dark medieval WWII Lovecraft dieselpunk, worn gunmetal and dirty olive with brass details.
Three-quarter isometric camera, full figure on a low dark oval beveled rubble base.
Entire subject centered, complete weapon and base within central 76% width and 80% height, generous empty margins.
Genuine transparent RGBA background, no painted checkerboard, no scene or floor outside the base.
No text, labels, logos, insignia or extra subjects. Square image.
```
